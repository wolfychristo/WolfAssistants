# WolfAssistants Lead Scraper Extension

A browser extension for scraping leads from multiple platforms and automatically adding them to WolfAssistants with AI-generated research notes.

## Supported Platforms

- 🌐 **Company Websites** - Scrapes contact info and validates SEO/UX/Content
- 💼 **LinkedIn Profiles** - Extracts profile information
- 🏢 **LinkedIn Companies** - Extracts company information
- 📍 **Google Maps Businesses** - Scrapes business listings
- 📷 **Instagram Profiles** - Extracts profile and bio information

## Features

- **Real-time Scraping** - Only extracts real data visible on the page (no fake data)
- **Website Validation** - Automatically checks SEO, UX/UI, and content issues
- **Purpose-Aware Research** - AI generates research notes based on your profession
- **Multi-Platform Support** - One extension for all platforms
- **Auto-Add to Contacts** - Seamlessly adds scraped leads to your WolfAssistants account

## Installation

1. Open Chrome/Edge → Extensions → Developer mode
2. Click "Load unpacked"
3. Select the `extension` folder
4. The extension icon will appear in your toolbar

## Usage

1. Navigate to any supported platform (website, LinkedIn, Google Maps, Instagram)
2. Click the extension icon
3. Click "Scrape [Platform Name]"
4. Review the scraped contacts and validation results
5. Click "Add to WolfAssistants" to save contacts with auto-generated research notes

## Setup

1. Make sure your backend is running on `http://localhost:8000`
2. When you first use "Add to WolfAssistants", you'll be prompted for your authentication token
3. The token will be saved for future use
